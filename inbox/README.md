# 資料置き場

AI に読んでほしい資料（Word・PDF・Excel・PowerPoint・テキスト・CSV）を入れておく場所です。
リポジトリを非公開にしていると、Issue に添付した資料は AI が読めないため、ここに入れてから頼みます。

## 使い方

1. 資料置き場に資料を入れる
   - このページの右上の **「Add file」→「Upload files」** を押す
   - 資料をドラッグし、下の緑の **「Commit changes」** を押す（確認の画面が出たら、もう一度「Commit changes」）
2. Issue に、資料の名前を書いて頼む
   - 例: `@claude 資料置き場の「営業_原稿.docx」で、営業のページを更新してください`
   - 名前の「.docx」は省いてもかまいません。後ろに「 (1)」などが付いているときは、そこまで書いてください（書かないと、AI が「これのことでしょうか」と確かめます）
   - Issue に添付してしまった資料を、同じ名前のままここに入れたときは、`@claude 資料置き場に入れました` だけで大丈夫です

## 知っておくこと

- **AI が読むのは、そのIssueで名前を書いた資料だけです。** 前に入れた資料が残っていても読みません
- 前から置いてある資料の名前を書いたときは、AI が「この資料でよいですか」と確かめます
- 同じ名前で入れ直すと、新しい資料に置き換わります
- 写真は、ここではなく Issue のコメントに直接貼ってください
- いらなくなった資料は、資料を開いて右上の「…」→「Delete file」で消せます（このページの説明 README.md は消さないでください）
- ここに入れただけでは、本番サイトは変わりません
- **非公開のリポジトリでだけ使ってください。** 公開のリポジトリでは、ここに入れた資料を誰でも見られます
