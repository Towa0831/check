# 写真を選ぶ・加工する

貼られた写真は、どの作業（news、recruit、edit）でも、この手順で選び、必要なら加工してから保存する。保存したあとは、それぞれの作業の手順に戻る。

## 道具

| コマンド | すること |
| --- | --- |
| `python tools/photo_sheet.py` | 貼られた写真の一覧を、番号・元の名前付きで1枚の画像にする（`/tmp/issue-images/sheets/`） |
| `python tools/photo_sheet.py sheet 写真 写真 …` | 指定した写真を一覧にする（サイトの写真と見比べるときなど） |
| `python tools/photo_sheet.py grid 写真` | 目盛り（ピクセルの座標）付きの画像にする（`/tmp/issue-images/grid/`） |
| `python tools/photo_sheet.py zoom 写真 X1,Y1,X2,Y2` | 範囲を拡大する（`/tmp/issue-images/zoom/`） |
| `python tools/photo_sheet.py compare 加工前 加工後` | 2枚を並べる（`/tmp/issue-images/compare/`） |
| `python tools/prepare_image.py 元の画像 保存先 [オプション]` | 加工して保存する（オプションは下の 3〜5。ぼかしは 3 の確認のあとだけ） |

作った確認用の画像は、**Read で開いて見る**。座標は、どの道具でも「写真の向きを直したあとの、元の大きさのピクセル」で共通。

## 1. 写真を見て、選ぶ

1. `/tmp/issue-images/list.txt` の「元の名前」（貼ったときのファイル名。例: `goto_09`）と、取り込んだ名前（`image-3.jpg`）を対応させる。担当者は元の名前で指示してくる。元の名前が空のときは、貼られた順番と場所で確かめ、迷ったら一覧の番号で担当者に聞く
2. `python tools/photo_sheet.py` で一覧を作り、全部の写真を見る
3. 指示に合わせて選ぶ
   - 「使わないで」と言われた写真は使わない
   - 選び直してよいと言われたら、目を閉じていない、ぶれていない、主役の顔が見える、明るすぎ・暗すぎない、ほかのページの写真と雰囲気が近いものを選ぶ。サイトの写真と見比べるときは `python tools/photo_sheet.py sheet site/assets/img/photo/job-manufacturing.jpg …`
   - 使わなかった写真で、指示に名前が出ていたものは、返事で「使いませんでした」と書く

## 2. 写っているものを確かめる（指示がなくても必ず）

使う写真に、次のものが写っていないかを、一覧と拡大（`zoom`）で確かめる。

- **主役以外の人の顔**：奥に小さく写っている人、半分だけ写っている人、ガラスや画面に映り込んだ人も
- **読める文字**：ホワイトボード・予定表・掲示物、パソコンや携帯の画面、書類、伝票や宛名、名札や名前の刺しゅう、車のナンバー

見つけたら:

- **ぼかしは、頼まれるまで行わない。** 原稿や資料に「ぼかして」と書かれていても、すぐにはぼかさない（下の「3」の確認をしてから）
- まず、ぼかさずに済む方法を考える
  - 切り抜き（トリミング）で、写真の外に出せるか（下の「4」。枠の比率のまま、主役を中心にして外に出せる範囲を探す）
  - 写っていない別の写真があるか（選び直してよいと言われているとき）
- 提案のときに、どの写真のどこかと、ぼかさずに済む方法を書いて、どれにするかを聞く。勝手に加工しない
  - 例: 「goto_05 の右奥に、別の方の顔が写っています。①右側を切り抜きで外す（主役は真ん中のまま）②別の写真（goto_07）にする ③このまま使う のどれにしますか」
  - このときも、ぼかしは自分からは勧めない

## 3. ぼかしを頼まれたとき（すぐには作業しない）

AI のぼかしは、精度が高くない。ぼかしたところが目立って写真の印象が変わったり、主役の顔に少しかかったりすることがある。そのため、頼まれても**まず作業せずに**、次のように伝えて、もう一度確かめる。

> AI のぼかしは精度が高くなく、ぼかしたところが目立ったり、主役の顔に少しかかったりすることがあります。代わりに、次の方法もあります。
> - 切り抜き（トリミング）で、写したくないものを写真の外に出す（この写真なら〜のように切り抜けます）
> - 写っていない別の写真を使う（goto_〇〇 なら写っていません）
> - 画像編集のソフトやサービス（Photoshop、Canva など）や、制作会社・デザイナーに加工してもらい、加工した写真を貼る
>
> それでも AI でぼかす場合は、`@claude AIでぼかしてください` のようにコメントしてください。

- 切り抜きや別の写真で済む案があれば、具体的に書く（どの写真を、どう切り抜くか）
- 原稿や資料に「ぼかして」と書かれていたときも、この確認をする。返事が来るまで、その写真は保存しない（文章など、ほかの作業は進めてよい）
- 担当者が加工した写真を貼り直したときは、それを使う（もうぼかさない。切り抜き・トーンも、頼まれたときだけ）

「それでも AI で」と返事があったときだけ、ぼかす:

1. `python tools/photo_sheet.py grid 写真` を Read で見て、ぼかす範囲の左上（X1,Y1）と右下（X2,Y2）を読む。細かいところは `zoom` で拡大して読む
2. 範囲は、隠したいものを囲む。顔は髪・耳・あごまで、文字はその紙や板まで。境目は道具が自動で外側へなじませるので、必要以上に広げない（広げるほど、ぼかしが目立つ）
3. 顔は `--blur-face X1,Y1,X2,Y2`（だ円）、文字や画面は `--blur X1,Y1,X2,Y2`（四角）。何か所でも並べて書ける
4. **主役の顔は、必ず `--keep X1,Y1,X2,Y2` で「ぼかさない範囲」にする**（髪・耳・あごまで）。主役のすぐ近くをぼかすときに、ぼかしやなじませた境目が、主役の目や顔にかからないようにするため。写真の中の、ほかの見せたい人の顔も同じ

## 4. 枠に合わせて切り抜く

写真が入る枠の縦横の比率は、サイトで決まっている。枠と写真の形が違うと、サイトが写真の**真ん中**を基準に自動で切るため、主役が端にいると切れてしまう。指示があるとき、または主役が真ん中にいないときは、枠の比率で、主役を中心に切り抜く。

| 使う場所 | 切り抜き方 |
| --- | --- |
| 社員紹介の写真（人を知る、職種ページの「この職種の人」） | `--crop 3:4 --focus 顔のX,Y`（縦長） |
| 職種の写真（仕事を知るのカード 16:10、職種ページの上 21:8、社員紹介から職種へのリンク 21:9） | `--crop 16:9 --focus 主役のX,Y`。どれも横長で、細長い枠では上下が切れるので、主役が上下の真ん中あたりに来るようにする |
| 社員インタビューの途中の写真、ニュースの記事の写真 | 写真の形のまま表示される。切り抜きは指示があるときだけ |

- 人物が小さく写っていて、寄りたいときは `--zoom 0.7` のように足す（比率に合う最大の範囲の7割を使う）
- 範囲を直接決めたいときは `--crop-box X1,Y1,X2,Y2`
- 写真の端にいる人や物は、切り抜きで外に出せる。外に出したものは、ぼかさなくてよい。**ぼかすより先に、まずこの方法を考える**

## 5. トーンを合わせる

- 「トーンを合わせて」「ほかの写真と雰囲気をそろえて」と言われたら `--tone auto`。サイトの写真の平均（明るさ・コントラスト・色の濃さ・色味）に、差の半分だけ近づける。強めにするときは `--tone auto:0.8`
- 「もう少し明るく」など具体的なときは、手で調整する: `--brightness 1.1`（明るさの倍率）、`--contrast 0.95`、`--saturation 1.1`（色の濃さ）、`--warmth 6`（赤み。マイナスで青み）
- 数字だけで決めず、`compare` で前と後を並べて、肌の色や白い壁が不自然になっていないか見る

## 6. 保存して、確かめる

1. 切り抜き・トーン（頼まれて確かめたあとなら、ぼかしも）を、1回のコマンドでまとめて行って保存する

   ```
   python tools/prepare_image.py /tmp/issue-images/image-4.jpg site/assets/img/photo/person-goto.jpg \
     --crop 3:4 --focus 815,370 --tone auto
   # ぼかすとき（3 の確認のあと）: --blur-face 1515,250,1785,630 --blur 85,820,255,1005 --keep 700,180,980,560 を足す
   ```

2. ぼかしたときは、出力に並んだ `zoom` のコマンドを全部実行し、Read で見て確かめる
   - 顔や文字が分からないこと。分かるときは、範囲を少し広げて、同じ保存先にもう一度保存する
   - 主役の顔（`--keep` の範囲）に、ぼかしがかかっていないこと。かかっていたら、`--keep` の範囲かぼかす範囲を直す
   - ぼかしの境目が、くっきりした線になっていないこと
3. `python tools/photo_sheet.py compare 元の画像 保存先` で全体を見て、主役が切れていないか、トーンが不自然でないか、ぼかしたところが目立ちすぎていないかを確かめる。目立つときは、切り抜きで外す案を担当者に伝える
4. **ここまで終わってから**、変更を保存（コミット）する

## 守ること

- **ぼかすと決まった写真は、ぼかす前のものを `site/` に保存しない**。保存するのは、`prepare_image.py` で加工が終わった1枚だけ。GitHub には変更の記録が残り、一度保存（コミット）したものは消せない。だから、ぼかしの確認はコミットの前に終える（担当者が「このまま使う」と決めた写真は、そのまま保存してよい）
- 写真の中の人の顔や体を描き変えない。写真の真ん中にいる人を消すことはできない（ぼかすか、写真を選び直す）
- 確認用の画像（`/tmp/issue-images/` の中のもの）は、サイトに使わない
- 返事には、写真ごとに何をしたかを書く: どれを使い、どれを使わなかったか／どう切り抜いたか／トーンをどうしたか／（ぼかしたときは）どこをぼかしたか。ぼかしたときは、最後に「ぼかしの見落としや、目立つところがないか、確認用ページで目でも確かめてください」と添える
